# Lógica de Programação com JavaScript e TypeScript

> Repositório didático: exemplos e listas de exercícios de lógica de programação resolvidos em sala de aula.

## Sobre o projeto

Exemplos e exercícios das aulas de **lógica de programação**, resolvidos em JavaScript (com alguns em TypeScript). Os arquivos seguem a sequência do material didático: programação sequencial, decisão, repetição, vetores, matrizes, objetos, classes e funções.

## Contexto acadêmico

Exercício aplicado em sala de aula, usado como prática guiada com os alunos.

## Organização dos arquivos

- `lXYqNN.js`: questões das listas de exercícios (ex.: `l041q05.js` = lista 04.1, questão 05).
- `l03*`: programação sequencial (entrada, processamento e saída)
- `l04*`: estruturas de decisão (`if`, `else`, `switch`)
- `l05*`: estruturas de repetição (`for`, `while`)
- `l06*` e `l07*`: listas complementares
- `01` a `08` (exemplos): vetores, matrizes, objetos, vetores de objetos, classes, métodos e funções (escopo global e local)
- `exvet*.js`: exercícios de vetores com `for` clássico e `for...of`
- Arquivos `.ts`: versões em TypeScript de alguns exercícios, para introduzir tipagem estática

## Tecnologias

- **JavaScript** (Node.js)
- **TypeScript** (`tsconfig.json` incluído)

## Como executar

Com o [Node.js](https://nodejs.org) instalado:

```bash
git clone https://github.com/fabcurvello/logicaprog.git
cd logicaprog
node l041q01.js
```

Para os arquivos TypeScript:

```bash
npx tsc 04exemploobjetos.ts
node 04exemploobjetos.js
```
